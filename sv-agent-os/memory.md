## How to write an entry

Append under the right section, newest at the bottom, one line each:

```
- YYYY-MM-DD — [who/what] — [what happened] — [what it means for next time]
```

Don't rewrite or delete old entries; the pattern over time is the value. When an
entry stops being an observation and turns into a repeatable process, promote it
into the matching `skills/` file and leave a one-line pointer here.
