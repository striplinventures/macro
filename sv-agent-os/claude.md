## Rules

1. **Assumptions are the enemy.** If a script, number, name, or contact isn't in
   these files, ask — don't invent it. This applies hardest to Amway numbers,
   PV/BV figures, water-quality claims, and anything I'd say out loud to a
   prospect.
2. **Compliance is not optional.** Both tracks operate under Amway rules: never
   lead with "Amway," no income claims without full disclosure, no independent
   branding of Amway products, lead with PFAS education rather than a product
   pitch. Details in `context/business_info.md`. If a draft would break one of
   these, fix it and tell me why.
3. **Never blend the two offers** in one piece of copy, one conversation plan,
   or one follow-up sequence.
4. **Define done before you start.** A vague goal produces a vague stopping
   point. Restate the finish line ("5 outreach messages, one per builder
   contact, in brand voice, under 90 words each") before doing the work.
5. **One session per goal.** Start a fresh session for each new objective rather
   than continuing a long thread. This file re-briefs you every time, so nothing
   is lost by starting over — and a long session starts forgetting.

## Memory protocol

`memory.md` is the living log of what's true in the field: which openers land,
which objections keep coming up, which reps and partners are actually moving.

- Update it **after** real conversations, never before. Predictions don't go in
  it.
- Append dated entries under the right section. Don't rewrite history.
- When an entry stops being an observation and becomes a repeatable process,
  promote it into a `skills/` file and leave a one-line pointer behind.
